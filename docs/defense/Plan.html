Day 4 — Time Tracking & Files

Theme: "I understand the timer state machine and the file storage model."

Morning 3h — Timer state machine

This is the most complex single feature. Open apps/timelog/models.py.

  1. Draw the state machine:
    • TimerSession: running ↔ paused → stopped (deleted on stop)
    • ActivityLog: append-only audit trail (start, pause, resume, stop)
    • TimeLog: created only on stop action
  2. Memorize the rules:
    • Only one running TimerSession per designer at a time
    • Starting a new task auto-pauses the previous one
    • elapsed_secs() calculation: accumulated_secs + (now - started_at) if running
  3. Read the timer endpoints in PROJECT_CONTEXT.md:
    • POST /api/timelogs/timer/start/ → creates TimerSession
    • POST .../stop/ → deletes TimerSession, creates TimeLog + ActivityLog

Day 6 — Analytics, BI & AI

Morning 3h — Analytical queries

Open DATA_MODEL.md → Key Analytical Queries. These 6 queries are the heart of your defense. Rewrite each one on paper with a plain-English explanation:

  2. Budget variance: SUM(estimated_hours) vs SUM(time_logs__hours_spent)

Evening 2h — Mock Q&A

Have a friend (or your mirror) ask you these rapid-fire:

Question One-sentence answer
Why email login instead of username? Agency staff change roles; email is stable and unique.
Why is is_active=False by default? Prevents login until invitation is accepted and password is set.
Why PROTECT on Project.client? Cannot delete a client who owns projects; prevents data loss.
Why separate Read/Write serializers? Read computes expensive aggregates; Write validates simple fields.
How does the timer survive a page refresh? TimerSession persists server-side; fetched on load via GET /timer/active/.
What prevents a Designer from editing another's time log? get_permissions() on TimeLogViewSet restricts PATCH/DELETE to Manager.
Why on_delete=CASCADE on Task but PROTECT on Client? Tasks are expendable child records; Clients are business entities with financial history.
How is scope creep calculated? COUNT(is_unplanned=True) / COUNT(*) * 100 per project.
Why Groq and not OpenAI? Faster inference, lower cost, llama-3.3-70b is sufficient for structured estimation.
What happens if a Designer starts Task B while Task A is running? Previous TimerSession auto-pauses; ActivityLog records pause for Task A, start for Task B.
If you can't answer in 10 seconds, study that topic for 30 minutes.
